# EcoSurvival: серверный мод для Eco

Мод делает выживание в Eco жестче: хищники опаснее и умнее, голод делает животных свирепыми, туши травоядных, убитых хищниками, не остаются на земле.

## Статус

| Часть | Статус |
|---|---|
| Игровые правила (голод, свирепость, решения животных, судьба туши) | Реализованы, 23 теста проходят (`tests/EcoSurvival.Tests`) |
| Прикладной слой Eco (`src/EcoSurvival.Eco`) | Плагин собирается и загружается, но **хуки на живых животных не подключены. В игре мод пока ничего не меняет** |
| Сборка против реального Eco | **Не проверена.** Справочные DLL Eco в этом окружении недоступны |
| Тест в отдельном мире | **Не проведен.** Нужен запущенный сервер Eco, см. раздел «Тест в отдельном мире» |

Причина: в публичном репозитории EcoModKit DLL из `ReferenceAssemblies` являются заглушками Git LFS (по 130 байт), Steam из рабочего окружения недоступен. Внутренние точки перехвата (смерть животного, нанесение урона, выбор поведения) в публичной XML-документации описаны не полностью, поэтому их подключение нельзя проверить без реальных сборок.

## Игровые правила

### Голод

- Голод 0..100. Хищники (carnivore, omnivore) набирают его быстрее травоядных (`PredatorHungerPerHour` = 8, `HerbivoreHungerPerHour` = 4 в час).
- Стадии: Satiated < 40, Hungry 40..70, Starving 70..90, Ferocious от 90.
- Свирепость (ferocity) растет линейно от порога 55 до 100 и лежит в [0, 1].
- Множитель урона хищника: от 1 до `MaxDamageMultiplier` (по умолчанию 2.0).
- Множитель радиуса обнаружения: от 1 до `1 + MaxDetectionBonus` (по умолчанию 1.8).

### Решения животных (`AnimalMind`)

- Травоядный бежит, если угроза, усиленная стадом (+25% за каждого союзника, максимум 4), превышает порог 0.30. Иначе пасется, если голоден, или отдыхает.
- Хищник сытый отдыхает. Голодный без видимой добычи ищет.
- Голодный хищник против стада из двух и более особей с укрытием устраивает засаду. Это ожидание ничего не стоит.
- Иначе хищник атакует, если утилита охоты не ниже 0.5. Стадо снижает утилиту на 0.12 за каждую особь. Свирепость частично снимает это снижение, поэтому очень голодный хищник нападает на стадо.

### Судьба туши (`CarcassPolicy`)

- Травоядное, убитое животным-хищником (carnivore или omnivore), по умолчанию не остается на земле: хищник съедает тушу в момент смерти, и голод хищника снижается на `MealNutritionFraction` от ценности добычи.
- Если задано `PredatorKillCorpseDelaySeconds` > 0, туша создается и удаляется через указанное число секунд.
- Смерть от игрока, среды или от травоядного не меняет поведение: туша остается обычной.

## Структура

```
EcoSurvivalMod/
  src/EcoSurvival.Core/        Игровые правила, без зависимостей от Eco (netstandard2.1)
  src/EcoSurvival.Eco/         Плагин Eco, собирается только с EcoReferenceDir
  tests/EcoSurvival.Tests/     Тесты правил, без внешних пакетов (net8.0)
```

## Сборка и тесты

Требуется .NET SDK 8.

```
cd EcoSurvivalMod
dotnet run --project tests/EcoSurvival.Tests        # 23 теста, код выхода 0 при успехе
dotnet build src/EcoSurvival.Core                   # ядро
dotnet build src/EcoSurvival.Eco -p:EcoReferenceDir=<папка с Eco.Core.dll, Eco.Shared.dll>
```

Без `EcoReferenceDir` слой Eco пропускается. Справочные DLL брать из своей установки Eco (`EcoServer_Data/Managed` или аналогичной папки) либо из `Examples/ReferenceAssemblies` репозитория EcoModKit после `git lfs pull`. Эти файлы в мод не копировать и не публиковать (см. раздел «Правовые рамки»).

## Тест в отдельном мире

Требование: проверка в отдельном мире, сохраненные миры не затрагивать.

Порядок проверки (выполняется на вашей машине, в этом окружении невозможен):

1. Создать отдельную копию серверной установки Eco или отдельный экземпляр сервера с собственной папкой сохранений. Не указывать папку с существующими мирами.
2. Создать новый мир через мастер создания. Не загружать сохраненные миры.
3. Собрать мод с `EcoReferenceDir`, положить сборку в папку модов тестового экземпляра и разрешить ее в `Configs/ModKit.eco` согласно документации Eco. Точные параметры запуска и пути проверить по документации Eco, в этом репозитории они не подтверждены.
4. Проверить в мире: статус плагина в UI сервера показывает «Ready», логи не содержат ошибок загрузки.
5. После подключения хуков проверить: голодный хищник атакует сильнее (сравнить урон при сытости и при свирепости), травоядное, убитое хищником, не остается на земле, стадо травоядных убегает раньше одиночного.

Сохраненные миры до тестов не открывать и не копировать в тестовый экземпляр.

## Open items (что нужно для игрового эффекта)

Ниже перечислены публичные члены из `Examples/ReferenceAssemblies/*.xml`, которые подходят для подключения. Точная механика переопределения не подтверждена.

1. Урон хищника по игроку и по животным: `Eco.Simulation.Agents.Animal.TryDamage`, `Damage`, `Player.TryDamage`, `User.TryDamage`. Нужна точка, где урон применяется к цели; множитель `DamageMultiplier` применяется там.
2. Смерть животного и спаун туши: `Eco.Simulation.AnimalSim.SpawnCorpse(AnimalSpecies, Vector3)`. Нужна точка перехвата до спауна туши (или сразу после него с удалением). Без нее правило «туша не остается на земле» не работает.
3. Поведение хищника: `Eco.Simulation.Agents.AI.Brain<T>`, `Eco.Mods.Organisms.LandPredatorBrain.ReactOnBlock`, `Eco.Mods.Organisms.Behaviors.FindAndEatPlantsBehavior` (пример enumerator-поведения). Здесь подключаются `AnimalMind.Decide` и `HungerState`.
4. Тревога стада: `Animal.AlertNearbyAnimals`, `Animal.SetFleePositionAndDuration`. Здесь реализуется `Intent.Flee`.
5. Сохранение голода между перезапусками сервера. Сейчас голод сбрасывается при перезагрузке.
6. Конфигурация через UI сервера: `PluginConfig<T>` по образцу `WelcomeUserPlugin` из EcoModKit.

Пункт 2 и 3 требуют сверки с реальными сборками. Если сборка Eco покажет другие сигнатуры, правьте слой `src/EcoSurvival.Eco`, ядро менять не нужно.

Проверено по открытым источникам, не юридическая консультация.

- **§ 69e UrhG (Dekompilierung).** Декомпиляция и копирование кода программы разрешены только для получения информации, необходимой для совместимости независимо созданной программы. Условия: лицо имеет право использовать программу, информация не доступна иначе, действие ограничено нужными частями. Полученные сведения нельзя использовать для создания по существу подобной программы. Для этого мода декомпиляцию Eco не проводили. Использовались только публичные XML-справки и примеры из EcoModKit.
- **Бинарники Eco.** В репозиторий не помещены. Файлы в `ReferenceAssemblies` в этом клоне являются заглушками LFS. Справочные DLL брать из собственной установки Eco.
- **Распространение.** Публиковать мод с DLL Eco нельзя без явного разрешения Strange Loop Games. Публиковать только исходный код мода и инструкцию сборки.
